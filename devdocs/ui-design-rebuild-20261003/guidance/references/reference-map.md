# 按设计问题选择参考

参考用于校准已经明确的任务、信息关系和视觉方向，不替项目生成业务规则或默认布局。先看项目已有合格页面；它覆盖当前问题时直接沿用。只读取能解决当前缺口的说明与实际原图，不要求每个任务搜集一套品牌案例。

| 当前设计问题 | 可用参考 | 观察重点与边界 |
| --- | --- | --- |
| 后台查询、筛选与连续处理 | [后台与控件案例](domestic-ui-examples.md) `cn-ant-query`、`cn-arco-query` | 筛选与结果、字段顺序、选择与批量动作；不迁移示例业务与整套皮肤 |
| 企业功能入口与队列的区别 | `cn-feishu-approval` / 项目真实记录 | 搜索与分类、入口与处理对象；入口展示不能替代工作队列 |
| 小程序输入、提交与安全区 | `cn-tdesign-publish` / 真实表单契约 | 输入顺序、内容增长与操作位置；组件模板不能决定首页任务 |
| 移动记录、详情与返回 | `cn-tdesign-order` / [决策示例](design-examples.md) | 对象摘要、状态动作、展开细节与列表上下文 |
| 上传的对象内反馈 | `cn-weui-upload` / 项目上传组件 | 数量、进度、错误、重试与删除；不是装饰布局参考 |
| 内容发现与持续消费 | [移动产品案例](mobile-product-examples.md) `cn-xiaoyuzhou-discovery` | 内容层级与持续控制共存；没有持续任务时不添加播放条式部件 |
| 品牌首页与长内容阅读 | `cn-heytea-brand` / 项目材料 | 图像、字形、材料与阅读节奏；不把品牌首页移植到服务操作页 |
| 已有会员规则的服务与权益 | `cn-yili-member` / 真实资格与权益 | 功能权重与分组；示例成长值有不一致，不复制数值和运营功能 |
| 微信商品展示与结账 | `cn-hublot-wechat` / 真实购买路径 | 展示与操作密度变化、中文输入和平台导航；不复制黑红皮肤、订金规则 |
| 中文阅读、教程或技术材料 | 实际内容、项目渲染器与组件 | 字面、行长、章节定位、图表/代码和复制；不为极简删必要内容 |
| 视觉一致性与主题 | DESIGN.md、token、品牌/行业材料和任务匹配的成品 | 构图、文字角色、间距与颜色关系；不存在规范时提出方向，不能伪装成给定品牌 |

同为 App 或小程序不代表任务相同。输入服务、内容消费、会员运营与购物的案例各有适用条件；先匹配用户与任务，再匹配平台，最后观察视觉细节。资料不足时可以采用可说明的设计判断，但不能宣称已经研究或验证了不存在的依据。

## 外部补充

普通搜索用环境原生搜索，页面读取/操作用 `agent-browser`，GitHub、X 等平台任务按需用 `agent-reach`。可从站酷、UI 中国发现原创项目，从 UI Notes 查看产品截图，从产品/设计方原站核对背景与多屏说明。Mobbin、Refero、Component Gallery 等只在实际可访问或已接通时使用，不声称调用未连接的服务。

看到标题、点赞、推荐或作品封面不等于读过界面。区分产品截图、设计交付、概念稿和浏览器实测；版本未知就不称最新版，静态图不证明交互或效果。记录本次迁移的关系及不适用部分，必要参数由项目和运行画面校准，图像像素不是 CSS px / rpx。
