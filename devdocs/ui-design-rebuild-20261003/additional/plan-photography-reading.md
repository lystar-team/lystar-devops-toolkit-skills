# 摄影作品阅读页：结构方案与待校准的视觉决定

本次只出方案，不实现、不运行。范围保持“按主题阅读作品、进入项目详情”；不添加联系、预约、购物或其他业务。

## 已知事实与证据缺口

请求说明已有真实图片和品牌字体，但本轮没有收到文件、现有页面或路由契约。没有查看任何作品图像，没有运行页面，也没有核对字体字形、画幅与图片数量。下文是基于已知阅读任务提出的设计判断，不是已验证的视觉成品。

缺图片不妨碍推导阅读结构，但会影响首屏选择、构图、裁切、色彩、字面和加载体量。这些决定必须在材料到位后校准，不能用虚构图片或“高级、沉浸”等词代替。

## 任务与路径

进入 → 识别当前主题 → 按主题阅读作品 → 选择一个项目 → 进入已有详情页 → 返回原主题和阅读位置。

| 区域 | 默认呈现 | 作用与取舍 |
| --- | --- | --- |
| 页头与主题导航 | 当前主题名称、已有主题入口 | 让读者定位，不加通用副标题；主题名称与顺序沿内容事实源 |
| 作品序列 | 当前主题的真实作品图像、必要项目名称与详情入口 | 图像是内容主体，不把每件作品包成同权重卡片，不为填空加虚构说明 |
| 项目入口 | 从该作品或项目名称进入对应详情 | 沿用已有路由；点击目标和键盘焦点可识别 |
| 返回 | 恢复主题与阅读位置 | 避免读者重新寻找；具体恢复机制需核对现有站点 |

默认先呈现一个主题的阅读序列，其他主题保留切换入口，而不是把所有主题与缩略图同时展开。这个取舍是设计判断；如果真实内容是有顺序的跨主题叙事，应改为连续章节，不把现有叙事切碎。

## 视觉关系与实现条件

- 图像承担作品表达，主题与项目名称承担定位。构图应让作品先被看到，不用装饰徽章、彩色描边或空洞 description 制造重点。
- 暂按保留完整画幅组织作品，而非统一裁成一组方图。素材到位后核对作品是否允许裁切，再决定具体宽度、列数与首屏图像；不预先承诺全宽 Hero。
- 字体沿用给定品牌体系。标题、项目名与辅助文字分配不同角色，通过尺度、字重、行距与对齐建立层级；文件未到位，暂不确定字重、字号与字面比例。
- 主题之间用位置与间距形成阅读节奏。桌面根据画幅安排阅读宽度；手机按阅读顺序单列，关键信息不因窄屏丢失。不以“大留白”代替作品与文字之间的比例校准。
- 背景、文字与图片色彩的关系待实际素材校准。图片数量、尺寸和数据来源确定后，才安排占位比例与加载策略。

## 状态与验证

方案覆盖图片加载/失败、主题无作品、长项目名称、主题切换、详情进入和返回。失败时保留已知项目名称与可用入口，不虚构图片；未知机制写为待确认，不声称已实现。

需取得：作品文件与主题清单、品牌字体及可用字重、已有阅读页和详情路由、项目数据来源、当前视觉规范与返回机制。到位后在目标桌面与手机画面核对构图、裁切、排版、重点和阅读节奏，再实际验证主题切换、进入详情、返回位置与键盘操作。本轮上述运行与视觉校准均未执行。
