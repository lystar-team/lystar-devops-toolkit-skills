# 中文巡检 Web 样例运行记录

核验日期：2026-10-02。单组 guided 样例与父会话自评，未做旧版 baseline、盲评或独立模型对照。

## 输入、参考与参数

任务见 [fixture](fixture.json)。字段、设备、位置、300 字和三张照片限制属于本次给定示例，不是用户真实工厂资料。提交适配器本地等待 450 ms 后首次失败，下一次成功；没有连接业务 API。

- TDesign 发布图提供输入顺序、文字增长空间与底部操作权重的观察。
- WeUI 上传图提供状态在对象内部呈现的观察；样例只实现本地选图、计数与删除，没有真实上传进度。
- 字体为现有系统中文字体；正文 16 px，手机对象标题 21 px，桌面 24 px，辅助 13/14 px。按钮至少 46 px，照片删除至少 44 px。
- 采用 12/16/20/24/28 px 的本次样例间距角色；白色工作面、细分隔线、蓝色主动作及文字错误。这里没有业务项目 token，不把这些数值推广为全局值。
- 390 宽按单列输入，底部操作保留安全区；1440 宽内容最大 860 px，避免把短表单拉成整屏。

## 首次输出与修正

[首次源码](guided/first-output.html)为首版；[当前可运行页面](guided/index.html)为修正后的版本。首次照片删除按钮高 36 px，本轮改为至少 44 px。首次点击删除时按钮位于固定操作区后方；页面本身保留可滚动底部空间，滚动到附件后可删除。本轮按实际操作滚动验证可达性，没有把未滚动的点击失败写为删除成功。

## 已执行检查

[机器检查记录](guided/checks.json)保存 26 项断言，全部通过。检查脚本在本轮临时执行，没有加入新的项目测试框架。

## 参考库入口的单独检查

六组案例、八张图像的本地尺寸与来源记录相符。浏览页的小程序筛选显示两组、移动 Web 筛选显示一组；原图对话框可打开，Escape 关闭并回到原链接焦点。桌面和 390 宽无横向溢出，八张图片经查看区域加载后全部读取成功，console / page errors 无输出。

画面：[参考库桌面](guided/reference-gallery-desktop.png)、[参考库手机筛选](guided/reference-gallery-mobile.png)。这项检查证明资源入口可用，不证明所有国内产品模式的交互已通过。

## 结论与限制

保留参考前置、具体参数与运行反馈这组执行指导。已证实参考资源可读、样例能把输入、草稿和失败恢复落到 Web 页面；没有证据证明新版本比旧版本提升多少，不能把自评或 26 项检查称为设计质量准确率。

未执行：旧版对照、盲评、库存调拨留出场景、真实接口、真实上传、微信开发工具/真机、软键盘和屏幕阅读器/axe 全面检查。桌面与手机 Web 结果不替代这些证据。
