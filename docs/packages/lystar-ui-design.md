# lystar-ui-design

为页面、组件、后台、Dashboard、Landing Page、表单、表格、图表和移动端界面提供任务分析、视觉生成、实现与验收指导。

## 安装

从独立 Release 包解压后运行：

```bash
./install.sh --harness codex
```

从源码仓库运行：

```bash
./install-lystar-ui-design.sh --harness codex
```

安装后由 Harness 按 Skill 名称 `lystar-ui-design` 加载。它不增加 PATH 命令；图像生成和页面检查使用当前 Harness 已提供的能力。
